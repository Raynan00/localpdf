# LocalPDF teaser (25 s)

1920×1080, 30 fps. Render with:

```
npx hyperframes@0.8.140 render -q high -o out/localpdf-teaser-25s.mp4
```

`assets/scan.jpg` is a generated stand-in for a phone photo of a desk; drop in a real photo with the same name (4:3) to replace it. `assets/dots.svg` is the dot field, generated with a fixed seed so every render matches.

Beats: desktop photo (0 s), converter site and cookie banner (3 s), "It does not need to be." (7 s), right-click menu (10 s), three results (14.5 s), Photos / Contracts / Scans (18.5 s), wordmark (22 s).
